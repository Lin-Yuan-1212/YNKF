## 1.5 「定制开发」这一节和它的四张图

导航第 3 项 `定制开发` 是**普通锚点，没有下拉面板**（`index.html` 第 48 行）：
这一节只有四张卡片，没有需要展开的子栏目，所以没给它配 `data-menu`。
`js/menu.js` 只对带 `data-menu` 的栏目 preventDefault，所以点它会直接滚到 `#boards`。

图片走的是 `.boards` / `.board` 这套（`css/layout.css` 第 6.5 节）：两列、图在上说明在下，
承载样式和 `.card` 同一档（1px 描边 + `--r` 圆角），不是新造一套。
窄于 760px 变单列。深色主题下说明区压到 `#1d1d1f`、图托板给 `#2a2a2d`，
否则浅灰棚拍底会直接糊进黑背景。

**这四张图是渲染出来的产品形态示意，不是已交付实物照片。** 出处只写在 `index.html` 顶部注释里，
页面上按客户视角写成产品说明；节末那句"以项目原理图和结构图为准"是工程口径，不是免责占位。
以后有实物照片了，同名替换 `img/` 里那四个文件，然后跑一次 `tools/make-hero-thumbs.ps1` 把首屏缩图跟上，
HTML 一行都不用改。

同一批图在页面上出现两次，是有意分工，不是重复贴：

- **首屏第一排**（`.hboards`，`css/layout.css` 第 2b 节）：四块，图 + 名字，点任意一块滚到 `#boards`。
  用 `img/hero/` 的 640×451 缩图而不是原图 —— 首屏在折叠线以上，`loading="lazy"` 加了也没用，
  拿 322 KB 的原图当第一屏代价太大；640 宽 = CSS 里最大显示宽（约 300px）的 2 倍，2 倍屏下也不糊，四张共 141 KB。
- **`#boards` 分区**：四块大的，整图不裁切 + 每块一段交付口径说明，是客户真正要看细节的地方。

图高写的是 `clamp(120px,20svh,196px)` 配 `object-fit:cover`，**用 svh 而不是定死像素**，
这条经验来自极曜微那次"首屏内容把贴底的滚动条顶到折叠线以下"：图高跟着窗口高度收，
贴底的关键词滚动条就一定还在首屏里。矮窗口两档（`max-height:800/640`）收到 17svh / 14svh，
620px 以下从四列改成横滑一排（`scroll-snap`，每块 76% 宽、露出下一块一角暗示可滑）。
**尺寸这一档是被他推着定的**：第一版是 240×120 左右，他一句"首页图片太小"，
于是整排宽度从 `--maxw`(1024) 放宽到 1280、图高上限 120→196、名字 13→14px，文字那一叠没动。

没有 `products.html`：这站的"内容"是经营范围，不是上百个型号，所以做成单页，
也顺带避免了"两份顶部导航要手工保持一致"那个坑（共用 UI 只留一份源码）。

## 2. 令牌层只改了两处

1. `--grad` 由「蓝→紫→粉」改成「蓝→青→天蓝」。原来的偏消费电子，青绿更贴物联网/通信。
   `--accent` 还是 `#0071e3` 没动 —— 按钮、链接、图表描边都从它走，改了要连 effects.css 里三团光晕的颜色一起改。
2. 主标题限宽从 `16ch` 改成 `min(9.4em,100%)`。原因写在 `layout.css` 第 2 节注释里：
   `ch` 是"0"的宽度，汉字是 `1em`，两者差近一倍，用 16ch 卡八个字正好压在换行线上。

## 4. 待补清单（页面上都显示成虚线"待补"，没填假数据）

规矩写在 `css/layout.css` 第 9 节：没有的内容不许拿"看着像的"顶上，
所以电话、邮箱、地址、工作时间一律是 `.todo` 虚线灰字，而且**不是 `tel:` 链接**
（点了拨不出去，还会让人以为号码是对的）。

上线前必须补齐，都在 `index.html` 里：

1. 业务电话 / 邮箱 / 注册地址 / 工作时间 → `#contact` 分区那个四行面板（搜 `业务电话`）
2. 页脚「联系」栏的三处 `待补`（搜 `>联系</h5>`）
3. ICP 备案号 → 页脚 `footer__note` 那段
4. 许可项目的批文 / 许可证信息 → 「经营范围」分区许可栏末尾那句"批准文号与证书信息待补"。**批文没下来之前，页面上不能出现"已具备施工/电气安装资质"这类话**
5. 补完电话后，把导航右侧 `联系我们` 那颗胶囊从 `href="#contact"` 改成 `href="tel:号码"`（可选）

## 6. 想删掉一个版块

下拉面板和导航栏目是**成对**的：`data-menu="goods"` 对应 `id="menu-goods"`。
删面板就把对应栏目上的 `data-menu` 和 `<span class="caret">` 一起去掉，那个栏目会自动退回普通锚点；
只删一边会出现"点了没反应"的死链接（`js/menu.js` 对所有 `data-menu` 都 preventDefault）。
`定制开发` 是这一条的现成例子：它有导航栏目、有分区，但**没有面板**，所以点它就是直接滚过去。

`js/hover.js` 里的画廊拖动逻辑这站用不到（没有 `.rail`），留着不影响；
`base.css` 里那条 `[data-theme="dark"] .section--dark .card` 这站也没命中（重音带里放的是 `.scope__box`），
保留只是为了和 V2.0 那份组件互抄时行为一致。
